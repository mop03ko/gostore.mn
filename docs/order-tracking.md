# Захиалгын байршил, явц

Захиалгын бүртгэлд тулгуурласан байршлыг `order-tracking.js` болон
`order-tracking.css` гурван талд ижил дүрмээр харуулна.

- **Админ:** Захиалгууд → төлөв дээр дарахад байршил, дараагийн алхам,
  бүртгэлийн хугацаа, хөдөлгөөний түүх нээгдэнэ. «Явц шинэчлэх» нь тухайн
  захиалгыг дахин уншина. Засах цонхонд мөн байршлын хэсэг бий.
- **Агуулахын менежер:** жагсаалт болон захиалгын дэлгэрэнгүйд харагдана.
  Эрээн талын тайлбар хятад хэлтэй. Менежерийн агуулахын эрх өөрчлөгдөөгүй.
- **Улаанбаатарын менежер:** өөрийн агуулахад оноосон баталгаажсан захиалгуудыг
  нийлүүлэгчийн илгээлт, Эрээнд ирсэн, багцалсан үеэс нь жагсаалтаар болон
  кодоор хайж харна. Эрт үеийн харагдац зөвхөн унших эрхтэй; зураг нэмэх,
  зөрчил засах, хүлээн авах үйлдлийн өмнөх хязгаарлалт хэвээр.
- **Хэрэглэгч:** «Миний ачаа» → захиалгын дэлгэрэнгүй. Өөрийн захиалгын
  байршил, явцын түүх, өмнө бүртгэсэн агуулахын зургуудыг үзнэ.

## Байршил тодорхойлох дүрэм

| Бүртгэл | Харагдах байршил |
| --- | --- |
| Нийлүүлэгчээс илгээсэн | Нийлүүлэгч → Эрээн агуулах |
| `erenhot`, `erenhot_ready` | Тухайн захиалгын Эрээн агуулах |
| `erenhot_dispatched` | Эрээн агуулах → Замын-Үүд |
| `zamyn_uud` | Замын-Үүд |
| УБ-д ирсэн, ангилж байгаа, авах/хүргэхэд бэлэн | Тухайн захиалгын УБ агуулах |
| `out_for_delivery` | Хэрэглэгч рүү хүргэлтэд |
| `completed` | Хэрэглэгчид хүлээлгэн өгсөн |

Багц бэлэн болсноор замд гарсан гэж үзэхгүй. Менежер илгээснийг батлахад
`erenhot_dispatched` болж өөрчлөгдөнө. Нийлүүлэгчийн `TaoWorld: shipped`
мэдээллийг зөвхөн `confirmed`/`shipping` үед ашиглана; агуулахын дараагийн
баталгаажсан хөдөлгөөнийг буцаахгүй.

Хугацааг одоогийн төлөвтэй таарах сүүлийн түүхээс авна. Дотоод тэмдэглэл
зассан хугацааг хөдөлгөөний хугацаа гэж харуулахгүй. Нийлүүлэгчийн мэдээлэл
бол шалгасан хугацааг тус эх сурвалжийн тайлбартай харуулна. Бүртгэлгүй
шатанд өнгөрсөн гэсэн тэмдэг тавихгүй. Энэ нь GPS байршил биш.

`GET api/index.php?action=admin-order&id=…` зөвхөн админы session шаарддаг;
нийлүүлэгчийн API дуудахгүй, захиалга өөрчлөхгүй. Хэрэглэгч болон менежер
өмнөх эрхээр хязгаарлагдсан API-гаа ашиглана. Нэгдсэн харагдац дотоод багцын
код, хувийн тэмдэглэл, нийлүүлэгчийн raw өгөгдлийг гаргахгүй.

## Шалгалт

```powershell
.\tmp\tooling\node.exe tests/order-tracking.cjs
.\tmp\tooling\node.exe tests/run-logistics.cjs order-tracking-ui admin-orders-ui logistics-ui warehouse warehouse-batches logistics admin-management-ui
```

Эдгээр нь тусгаарласан локал өгөгдөл ашиглана. Нийтлэхдээ storefront bundle,
админ/агуулахын JS ба HTML, shared JS/CSS болон API-г хамт шинэчилнэ.
